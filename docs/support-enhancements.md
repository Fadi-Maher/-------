# تقييم المحادثة وتحسين تفاعل المساعد

النمط Extension: تُحفظ الهوية والخطوط ومفاتيح الاستعادة والمسارات وصلاحيات المالك. تبقى التقييمات القديمة مفيدة/غير مفيدة مستقلة ولا تُحوّل إلى نجوم وهمية. دقة الهوية10، الاعتماد على الأصول2، كثافة المعلومات5، التباين البصري3، الحركة3.

تظهر بطاقة1–5 نجوم بعد إنهاء العميل للمحادثة أو إغلاقها من المالك. إغلاق المحادثة لا يلغي الطلب ولا يغيّر بياناته. التقييم اختياري، مع ملاحظة حتى500 حرف وموافقة عند الإرسال. يمكن للعميل الذي لا يحفظ محادثته إرسال تقييم دون تفعيل حفظ السجل. يُحفظ feedback بمعرف UUID منعًا لتكرار المحاولات، ومحادثة محفوظة واحدة لا تقبل أكثر من تقييم واحد. تعرض التحليلات متوسطًا وتوزيعًا من السجلات الفعلية وملاحظات منقحة للمالك فقط، مع حالة صفر صادقة.

تبقى الأسئلة الشائعة متاحة قرب حقل الكتابة حتى بعد الرد الأول. تعرض3 موضوعات مع توسيع التسعة وتظل اقتراحات متابعة السياق موجودة داخل السجل. تُعطل عند طلب جاري أو خطأ أو انتقال لبشري أو الإغلاق.

مؤشر الكتابة ثلاث نقاط بتدرج160ms ودورة1.1s (الدورة حالة تحميل وليست حركة دخول). يتحرك كل عنصر2px باستخدام transform/opacity فقط. عند تقليل الحركة تبقى نقاط ثابتة والنص، دون تغيير بقية الموقع أو فرض انتظار مصطنع.

الأصول: BrandMark وAssistantAvatar الحاليان؛ لا أصول تصوير إضافية. المرجع الرسمي للإعلان الحي لسجل الرسائل محفوظ سابقًا في docs/support-design.md.

حالة الترحيل: سجل قاعدة البيانات السابق لا يغطي جميع جداول المشروع الموجودة. لذلك وُلد0026_smart_sandman.sql من المخطط ثم طُبق عبر db:support-feedback، الذي يراجع الجدول والقيود والفهرس ويغيّر الجدول الجديد فقط. لم يُعد تشغيل الترحيلات القديمة ولم تُعد كتابة سجلها.

التحقق: نجحت اختبارات محرك الدعم17 وصلاحيات API8 وواجهة React14، ثم تكامل الدعم الحقيقي3 (الحفظ والاستعادة والتصعيد والرد البشري والإغلاق والتقييم المجهول ومنع التكرار وحذف السجل). نجح TypeScript والبناء. ظهر في المجموعة الكاملة اختبار تتبع قديم يتوقع كشف تفاصيل الطلب للزائر؛ عُدل الاختبار فقط ليؤكد رفض الزائر ثم يستخدم جلسة المالك. لم تتغير صلاحيات التطبيق أو سياسة OTP الإنتاجية.

النتيجة النهائية: نجحت المجموعة الكاملة بعد تصحيح اختبار التتبع القديم (582 اختبارًا في73 ملفًا). أُعيد فحص TypeScript والبناء واختبارات واجهة الدعم14 بعد إضافة تمييز «قيد الإرسال»؛ جميعها ناجحة. تمت معاينة دعم الطلبات على1440×1000 و390×844. مهارة safe-order-support-chat اجتازت quick_validate.
